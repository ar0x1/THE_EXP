## ✦ About

**THE EXP** is a gallery of visual web experiments, creative coding projects, and interactive browser experiences. Each experiment has its own page, presented inside a shared showcase.

Built with **HTML, CSS, and JavaScript**, the collection explores creative possibilities across modern web technologies.

## ✦ Features

- **Creative Experiments** — CSS art, interactive effects, games, and animations.
- **WebGL & 3D** — immersive visuals, shaders, and procedural graphics.
- **Interactive Gallery** — browse experiments through a unified interface.
- **Responsive Design** — layouts for desktop, tablet, and mobile.
- **Lazy-Loaded Previews** — load previews as they approach the viewport to reduce unnecessary work.
- **No Build Step** — the gallery itself uses vanilla HTML, CSS, and JavaScript.

## ✦ Getting Started

Just clone the Repository ✅ and enjoy the Projects.

Each experiment lives in its own directory under `projects/`, with `index.html` serving as its entry point.

## ✦ Add Your Own Experiment

1. Create a directory inside `projects/`.
2. Add an `index.html` file containing your experiment.
3. Register its slug, title, category, and description in the `PROJECTS` array inside `LAB.html`.
4. Test its preview and direct link.
5. Verify the gallery on desktop and mobile.

## ✦ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- SVG and Canvas
- WebGL for supported experiments
